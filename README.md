# BranchRunner

**Turn scoped engineering work into review-ready pull requests.**

[BranchRunner](https://branchrunner.com) builds coding-agent orchestration software for engineering organizations. It brings tasks, coding agents, isolated workspaces, validation, and human approvals into one system, with evidence that follows the work from issue to pull request.

## What BranchRunner does

- **Keeps work durable.** Objectives, requirements, decisions, and conversations stay with the task across sessions and repeat attempts.
- **Coordinates multiple agents.** Primary and specialist agents work in separate Git worktrees, with visible roles, activity, and costs.
- **Isolates execution.** Docker workspaces and Git worktrees give each run its own environment and checkout.
- **Connects requirements to evidence.** Tests, type checks, preview checks, and independent review help people assess what changed and what was verified.
- **Keeps humans in control.** Approval policies, intervention, and spend, token, and time budgets bound agent autonomy.

The platform is provider-neutral, with workflows around OpenAI Codex, Claude Code, Gemini CLI, and OpenCode. GitHub integration is available; GitLab, Linear, and Jira integrations are planned.
